= AI Image Generator

A Spring Boot web application that generates images using OpenAI's DALL-E 3 model, with AI-assisted prompt suggestions.

== Features

* *AI Image Generation* - Generate images using DALL-E 3
* *Smart Prompt Suggestions* - AI suggests detailed prompts from simple keywords
* *Multiple Prompt Styles* - Choose from Creative, Professional, Fun, Realistic, Artistic, Fantasy, or Minimalist
* *Image Options* - Configure size (Square/Landscape/Portrait), quality (Standard/HD), and style (Natural/Vivid)
* *Download Images* - Download generated images directly
* *Generation Metadata* - View model, generation time, and settings used

== Tech Stack

* Spring Boot 3.5
* Spring AI 1.1 (OpenAI + Ollama integration)
* JTE (Java Template Engine)
* Java 21

== Prerequisites

* Java 21+
* OpenAI API Key (for image generation)
* Ollama (optional, for local prompt suggestions)

== Configuration

Set your OpenAI API key as an environment variable:

[source,bash]
----
export OPENAI_API_KEY=your-api-key-here
----

Or add it to `src/main/resources/application.properties`:

[source,properties]
----
spring.ai.openai.api-key=your-api-key-here
----

== Running the Application

=== Default Profile (OpenAI for everything)

[source,bash]
----
./mvnw spring-boot:run
----

=== Ollama Profile (Ollama for chat, OpenAI for images)

First, make sure Ollama is running with a model:

[source,bash]
----
ollama pull llama3.2
ollama serve
----

Then run with the ollama profile:

[source,bash]
----
./mvnw spring-boot:run -Dspring-boot.run.profiles=ollama
----

NOTE: Ollama is used for prompt suggestions only. Image generation still requires OpenAI (DALL-E 3) since Ollama doesn't support image generation.

Then open http://localhost:8888 in your browser.

== Usage

=== Generate an Image

1. Enter keywords in the "Your idea" field (e.g., "sunset beach palm trees")
2. Select a prompt style (Creative, Professional, Fun, etc.)
3. Click *Suggest Prompt* to get an AI-generated detailed prompt
4. Optionally edit the prompt
5. Choose image size, quality, and style
6. Click *Generate Image*
7. Download the image using the *Download Image* button

|Magical, mythical, epic landscapes

|Simple, clean, elegant designs

=== Image Options

* *Size*: Square (1024x1024), Landscape (1792x1024), Portrait (1024x1792)
* *Quality*: Standard, HD
* *Style*: Natural, Vivid
